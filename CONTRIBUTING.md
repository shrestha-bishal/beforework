# Contributing

Thanks for your interest in Beforework.

## Getting started

1. Fork the repository and create a branch for your change.
2. Run the site locally with `python3 -m http.server 8000`.
3. Test the affected workflow in Chrome or Edge, including file creation and saving where relevant.
4. Keep changes focused and use Australian English for user-facing copy.
5. Open a pull request describing the behaviour changed and how it was tested.

## Pull requests

Please include screenshots for visible interface changes. Avoid committing workspace JSON files, credentials, build output, or personal data.

## Issues

For bugs, include the browser and operating system, steps to reproduce, expected behaviour, and actual behaviour. Do not include private workspace files or access tokens in an issue.
