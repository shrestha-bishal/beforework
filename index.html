Connect your Beforework file

Beforework is a serverless, local-first, privacy-first project workspace. Your data is never transmitted to a server or third party - projects are saved directly to a JSON file on your device, which you retain full ownership and control of, the same as any other file on your computer.

Changes are written to the file immediately, with no intermediate save step and no data held outside the file itself. Work is preserved exactly as it was left, whether resumed later, on the same machine, or on another device.

For access across multiple devices, the file can be stored in a synced folder such as OneDrive or Google Drive; it will sync using the same mechanism as any other document in that folder, requiring no additional configuration.

Each project supports list, table, board, and calendar views, with items organized into groups and tracked by priority, due date, and tags.

Choose an existing file or create a new one to get started.
